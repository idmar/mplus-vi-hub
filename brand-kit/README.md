# M+ 品牌视觉套件（Brand Visual Kit）— 研究性重建

基于 M+ 官方资料（thonik 官网项目故事、Dezeen 报道、M+ 年报内页）重建的品牌视觉套件。
thonik 未公布官方 hex 色值与字体声明；本套件色值全部从 thonik 官方发布的项目图片中采样提取，仅供研究与学习。

## 文件清单
| 文件 | 内容 |
|---|---|
| mplus-palette.svg | 中调色板卡：15 主色 + 3 中性色，中英双语命名 + hex |
| mplus-colour-wheel.svg | M+ 色轮重建（12 中调色段 + 50% 灰轮心），依据年报「A New M+ Visual Identity」图 |
| mplus-pattern-1~4.svg | 「+」加号满版图案，复原年报 4 组官方配色 |

## 核心规则（据官方应用方式总结）
1. 全部色彩明度校准至等同 50% 黑 —— 中调色背景上黑/白文字均清晰可读
2. 图形母题：建筑倒 T 形 / 加号「+」及其平铺图案
3. 双语排版：英文横排、中文竖排（呼应「+」的两个方向）
4. 色彩组合追求「visual tickle」：意外而悦目的中调色并置
5. 字体（官网核查）：西文 Simplistic（Bold Monday 定制版），中文 Noto Sans TC/SC
